Інтерактивний модуль: Степінь з натуральним показником

📚 Блок 1. Що таке степінь?

Степенем числа a з натуральним показником n (де n > 1) називають добуток n множників, кожен з яких дорівнює a.

an = a · a · ... · a (всього n множників)

• a (основа) — число, яке помножують саме на себе.
• n (показник) — скільки разів це число повторюється.

Парний показник (2, 4, 6...):
Результат завжди додатний.
Приклад: (-3)² = 9
Непарний показник (3, 5, 7...):
Результат зберігає мінус від'ємний.
Приклад: (-2)³ = -8
📑 Блок 2. Властивості степенів

Головні правила, які допоможуть швидко спрощувати математичні вирази:

Операція Формула Що робити з показниками?
Множення am · an = am+n Додавати (+)
Ділення am : an = am-n Віднімати (-)
Піднесення до степеня (am)n = am·n Перемножувати (·)
🎯 Блок 3. Експрес-тренажер знань
Успішно виконано: 0 з 3

1. Обчисліть значення виразу: 2⁴

2. Спростіть вираз: 5³ · 5⁴

3. Подайте у вигляді степеня: (x³)⁴
